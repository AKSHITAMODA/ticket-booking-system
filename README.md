# Ticket Booking System

Production-oriented starter for a deployable ticket booking platform.

## Planned stack
- Backend: Java 21 + Spring Boot + PostgreSQL + Redis
- Frontend: React + Vite
- Deployment: Vercel (frontend) + Render/Railway (backend)
- Containerization: Docker

## Current milestone
This is the initial repository scaffold. We will build the system incrementally:
1. Backend health check
2. Database + Redis connectivity
3. Authentication and RBAC
4. Venue and seat management
5. Events/shows
6. Seat holds + TTL + concurrency protection
7. Booking/cancellation
8. Waitlist
9. QR/email
10. WebSockets
11. Testing
12. Docker + deployment

See the supplied project specification for the complete requirements.
